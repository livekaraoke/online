Live request repertoire

Choose the default Roxanna setlist used by the public request popup. Every song in the selected list is included; the list is still available only while requests are open.

The current public request rules require the source setlist to be named Roxanna. Other acts' lists cannot be published through this control. Edit the chosen list in the LiveSuite setlist editor to add or remove songs.

Website wording

All fields start with the current website wording. Edit only the fields you want to change. Your changes are plain text and apply to the public website without a code deployment.
