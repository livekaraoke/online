How this temporary report calculates things

It reads performanceSessions once and uses the archived requestSnapshot, playedSongsSnapshot, performanceLogSnapshot and summary fields already saved when a session ends. It does not open realtime listeners and does not write analytics back to Firestore.

“Played request” comes from request status (completed/played). “Performed” comes from the played-song/performance-log snapshots. These can differ legitimately, for example when you manually play a song that did not originate from a public request.
